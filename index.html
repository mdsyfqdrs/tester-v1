📋 Google Sheet URL — Buat Apps Script baru, tampal kod dari apps-script.js, deploy sebagai Web App.

📖 Cara Setup Google Sheets

Ikut langkah ini sekali sahaja

  1. Buka Google Sheets → buat spreadsheet baru
  2. Klik Extensions → Apps Script
  3. Padam semua kod lama, tampal kod dari fail apps-script.js
  4. Klik Deploy → New Deployment → Web App
  5. Set "Who has access" kepada Anyone
  6. Salin URL yang diberikan, tampal di atas
